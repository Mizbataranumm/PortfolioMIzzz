# Mizba Taranum Portfolio

A dark, interactive cybersecurity-focused portfolio for Mizba Taranum, built as a lightweight static site with HTML, CSS, and JavaScript.

## Live Focus

This portfolio positions Mizba as a:

**Full-Stack Developer | Application Security & Cloud Security**

The site highlights secure backend engineering, cloud security foundations, authentication systems, AI-integrated products, and planned cybersecurity projects.

## Features

- Cinematic loading screen
- Cursor glow interaction on desktop
- Animated hero with particles and typed tagline
- Sticky glass navbar with active section tracking
- Responsive mobile navigation
- About section with animated stats
- Skills grid with tech marquee
- Project cards with tilt, spotlight hover, and case-study modals
- Achievements section
- Scroll-progress journey timeline
- Contact form using a reliable `mailto:` flow
- Dark premium visual style
- Local resume download

## Run Locally

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 5500
```

Then visit:

```txt
http://localhost:5500
```
